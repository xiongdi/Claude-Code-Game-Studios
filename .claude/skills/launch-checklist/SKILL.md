> **仅显式调用**：此技能仅在用户使用 `/launch-checklist` 显式请求时运行。不要基于上下文匹配自动调用。

## 第 1 阶段：解析参数

读取发布日期或 `dry-run` 模式的参数。Dry-run 模式生成清单而不创建签字确认条目或写入文件。

---

## 第 2 阶段：收集项目上下文

- 读取 `CLAUDE.md` 获取技术栈、目标平台和团队结构
- 读取 `production/milestones/` 中的最新里程碑
- 读取 `production/releases/` 中的任何现有发布清单
- 如果存在，读取 `design/live-ops/content-calendar.md` 中的内容日历

---

## 第 3 阶段：扫描代码库健康

- 计算 `TODO`、`FIXME`、`HACK` 注释及其位置
- 检查生产代码中是否有任何 `console.log`、`print()` 或调试输出
- 检查占位符资产（搜索 `placeholder`、`temp_`、`WIP_`）
- 检查硬编码的测试/开发值（localhost、测试凭据、调试标志）

---

## 第 4 阶段：生成发布清单

```markdown
# 发布清单：[游戏标题]
目标发布：[日期或 DRY RUN]
生成日期：[日期]

---

## 1. 代码准备情况

### 构建健康
- [ ] 所有目标平台上的干净构建
- [ ] 零编译器警告
- [ ] 所有单元测试通过
- [ ] 所有集成测试通过
- [ ] 性能基准在目标范围内
- [ ] 无内存泄漏（通过扩展浸泡测试验证）
- [ ] 构建大小在平台限制内
- [ ] 构建版本在源代码控制中正确设置和标记

### 代码质量
- [ ] TODO 计数：[零个才允许发布，或有记录的例外]
- [ ] FIXME 计数：[零个才允许发布]
- [ ] HACK 计数：[每个都必须有记录的正当理由]
- [ ] 生产代码中无调试输出
- [ ] 无硬编码的开发/测试值
- [ ] 所有功能标志设置为生产值
- [ ] 错误处理涵盖所有关键路径
- [ ] 崩溃报告已集成并验证

### 安全
- [ ] 源代码中无暴露的 API 密钥或凭据
- [ ] 存档数据已加密
- [ ] 网络通信已保护（TLS/DTLS）
- [ ] 反作弊措施活跃（如果多人）
- [ ] 所有服务器端点的输入验证（如果多人）
- [ ] 隐私政策合规已验证

### 资产

## 3. 质量保证

### 测试
- [ ] 完整回归测试套件通过
- [ ] 零个 S1（关键）bug 未解决
- [ ] 零个 S2（重大）bug 未解决（或有记录的例外）
- [ ] 浸泡测试通过（8+ 小时连续游戏）
- [ ] 多人压力测试通过（如适用）
- [ ] 所有关键用户路径在每个平台上测试
- [ ] 边缘情况已测试（存储满、无网络、挂起/恢复）

### 平台认证
- [ ] PC：Steam/Epic/GOG SDK 要求满足
- [ ] 主机：TRC/TCR/Lotcheck 提交已准备
- [ ] 移动：App Store/Play Store 指南合规
- [ ] 无障碍：最低标准满足（重映射、文本缩放、色盲）
- [ ] 年龄评级已获得（ESRB、PEGI、地区）

### 性能
- [ ] 目标 FPS 在最低规格硬件上达到
- [ ] 加载时间在所有平台上在预算内
- [ ] 内存使用在所有平台上在预算内
- [ ] 网络带宽在目标范围内（如果多人）
- [ ] 关键时刻无帧卡顿
```
